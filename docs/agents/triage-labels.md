# Triage labels

Use these tracker labels whenever a skill refers to a canonical triage role.

- `needs-triage` → `needs-triage`: maintainer evaluation needed.
- `needs-info` → `needs-info`: waiting for reporter information.
- `ready-for-agent` → `ready-for-agent`: fully specified and ready for an agent.
- `ready-for-human` → `ready-for-human`: requires human implementation.
- `wontfix` → `wontfix`: will not be actioned.

Edit the label on the right when the tracker vocabulary changes.
